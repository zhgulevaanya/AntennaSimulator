# AntennaSimulator
Интерактивное приложение на C++/CLI (Windows Forms) для моделирования и визуализации диаграммы направленности плоской фазированной антенной решётки.

## Возможности

- **Плоская решётка Nx × Ny** — настраиваемые размеры и шаг элементов `d = beta × λ/2`
- **Интерактивная маска элементов** — клик по сетке включает/отключает отдельные излучатели (моделирование отказов, разрежения)
- **3D-диаграмма направленности** — каркасная визуализация `√(I/Imax)` с управлением камерой:
  - вращение мышью / стрелками клавиатуры
  - масштабирование колёсиком / клавишами `+` / `−`
- **Вид сверху** — тепловая карта в градациях серого (центр = зенит, край = горизонт)
- **Демонстрация grating lobes** — кнопка быстрой установки `d = λ` (beta = 2) для наглядного появления побочных максимумов

## Технические детали

- Расчёт поля: суперпозиция фазовых вкладов активных элементов
  `I(θ,φ) = |Σ exp(j·k·(x·sinθ·cosφ + y·sinθ·sinφ))|² / N²`
- Визуализация без сторонних библиотек — только `System.Drawing` + GDI+
- Цвет каркаса кодирует нормированную интенсивность (тёмный = максимум)

## Сборка

Требуется Visual Studio с поддержкой **C++/CLI** (`.NET Framework`, `System.Windows.Forms.DataVisualization`).

## Управление

| Действие | 3D-режим |
|---|---|
| ЛКМ + движение | вращение |
| Стрелки | вращение |
| Колёсико / `+` `−` | масштаб |
